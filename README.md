# Сводка — веб-версия

Сводки СВО и других конфликтов: лента с фильтрами, карта с зонами контроля, таймлапс линии фронта и история войн. Работает в браузере; на iPhone ставится на экран «Домой» (Safari → «Поделиться» → «На экран „Домой“»).

## Как устроено

- `web/` — сам сайт: `index.html`, `app.js`, `style.css`, данные в `web/data/`. Библиотек нет, карта рисуется на canvas по векторным данным.
- `tools/build_news.py` — сборщик: каждые 30 минут GitHub забирает RSS и открытые Telegram-каналы, раскладывает сообщения по конфликтам и темам, привязывает к местам и кладёт в `web/data/news.json`; свежую линию фронта — в `web/data/front.json`.
- `tools/build_timeline.py` — раз в неделю обновляет кадры таймлапса.
- `tools/build_conflicts.py`, `tools/war_models.py`, `tools/build_warmaps.py`, `tools/build_base.py` — подготовка зон контроля, моделей войн и подложки карты (запускаются вручную).
- `.github/workflows/site.yml` — расписание и публикация на GitHub Pages.

## Ограничения

- Лента обновляется раз в 30 минут, не мгновенно.
- Свои источники браузер читает через публичный прокси (allorigins.win, corsproxy.io) — они могут не работать.
- Зоны контроля вне Украины и линии фронта исторических войн — схема, собранная вручную.

## Лицензии и источники

Картографические данные — Natural Earth (общественное достояние); исторические границы — historical-basemaps (GPL-3.0); контроль территории на Украине — DeepState. Шрифты Unbounded и Golos Text — SIL OFL.
